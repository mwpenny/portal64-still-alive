# @incinerator

An incinerator which opens and closes in response to a [signal](../signals.md).

## Name Structure

```
@incinerator OPEN_SIGNAL_NAME
```

## Arguments

| Name                     | Description                                                     |
| ------------------------ | --------------------------------------------------------------- |
| `OPEN_SIGNAL_NAME`       | The name of the signal which will open the incinerator when set |
